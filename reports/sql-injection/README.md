# SQL Injection — Training Labs

**Platform:** PortSwigger Web Security Academy

## Overview

This section documents my hands-on SQL injection training in authorized laboratory environments.

## Topics Practiced

- SQL injection in WHERE clauses
- Authentication bypass
- UNION-based SQL injection
- Database enumeration
- Extracting data through vulnerable queries

## Documentation Status

I have completed SQL injection training labs on PortSwigger Web Security Academy. Detailed technical writeups, sanitized HTTP requests, impact analysis, and remediation guidance will be added after reviewing each lab.

## Security Recommendations

- Use parameterized queries.
- Avoid constructing SQL statements by concatenating untrusted input.
- Apply least-privilege database permissions.
- Handle database errors securely.

## Ethical Scope

All exercises were performed on authorized training laboratories.
