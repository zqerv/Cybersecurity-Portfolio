**Platform:** PortSwigger Web Security Academy

## Overview

This section documents my hands-on learning of Cross-Site Scripting vulnerabilities in authorized training environments.

## Topics Practiced

- Reflected XSS
- Stored XSS
- DOM-based XSS
- HTML and JavaScript injection contexts
- Understanding browser-side security risks

## Documentation Status

Completed training labs will be reviewed individually. Detailed writeups, sanitized evidence, impact analysis, and remediation recommendations will be added.

## Security Recommendations

- Apply context-aware output encoding.
- Avoid unsafe DOM manipulation.
- Use safe HTML sanitization when necessary.
- Implement Content Security Policy as an additional protective layer.
- Validate and review untrusted input handling.

## Ethical Scope

All testing was performed exclusively in authorized training laboratories.
